# Практическое занятие 12: Контрольная работа №2
Данный репозиторий содержит результат выполнения практических заданий 7-11.
Это полноценное fullstack-приложение (SPA), разработанное на связке Node.js (Express) и React.

## 🌟 Функционал приложения
Приложение представляет собой интернет-магазин корейской косметики с реализованной системой управления ролями (RBAC).

**Основные возможности:**
*   **Аутентификация и авторизация**: Регистрация, логин, выход. Используется подход с JWT-токенами (`AccessToken` - короткоживущий, `RefreshToken` - долгоживущий, хранится в HttpOnly cookies для повышения безопасности).
*   **Ролевая модель (User, Seller, Admin)**: Разграничение доступа как на клиенте (UI), так и на сервере (Middleware).
*   **CRUD для товаров**: Возможность просматривать каталог товаров с любого аккаунта. Создание и редактирование товаров (доступно продавцам и администраторам). Удаление товаров (доступно только администраторам).
*   **Панель Администратора**: Управление списком пользователей (доступно только администраторам). Позволяет просматривать всех зарегистрированных пользователей, редактировать их профили и роли, а также блокировать/разблокировать нарушителей. Заблокированные пользователи не могут войти в систему.
*   **Адаптивный UI**: Современный дизайн с использованием React Router для навигации без перезагрузки страницы (SPA). Защищенные маршруты не позволяют неавторизованным пользователям или пользователям с нехваткой прав заходить на закрытые страницы (происходит редирект).

## 🚀 Как запустить проект локально

Проект состоит из двух частей: сервера (backend) и клиента (frontend).
Для запуска вам потребуется установленный **Node.js**.

### 1. Запуск сервера
Откройте первый терминал и выполните следующие команды:
```bash
# Перейдите в папку сервера
cd pr11/server

# Установите зависимости
npm install

# Запустите сервер (по умолчанию работает на порту 3020)
npm start
```
*Сервер запустится по адресу: `http://localhost:3020`*

### 2. Запуск клиента
Откройте второй терминал и выполните следующие команды:
```bash
# Перейдите в папку клиента
cd pr11/client

# Установите зависимости
npm install

# Запустите React-приложение
npm start
```
*Клиент запустится по адресу: `http://localhost:3003`*

## 👮 Система Ролей (RBAC)
В приложении реализованы 3 роли:
1.  **Пользователь (user)**: Может просматривать список товаров, переходить на страницу деталей товара.
2.  **Продавец (seller)**: Наследует права пользователя + может добавлять новые товары на главной странице и редактировать уже существующие (появляются соответствующие кнопки).
3.  **Администратор (admin)**: Наследует права продавца + может удалять товары. Имеет доступ к специальной панели управления пользователями, где может назначать роли другим пользователям и блокировать им доступ к системе.

*Примечание:* для удобства тестирования, выбор роли (user, seller, admin) оставлен прямо на форме регистрации. В реальном Production приложении новые пользователи должны регистрироваться только как `user`, а повышение роли до `seller` или `admin` — осуществляться исключительно администратором.

## 🛠 Технологический стек
*   **Frontend**: React (Create React App), React Router DOM v6, Axios, Vanilla CSS.
*   **Backend**: Node.js, Express, jsonwebtoken (JWT), bcrypt (хеширование паролей), cookie-parser.
*   **Хранение данных**: In-memory массивы (работает до перезапуска сервера).
