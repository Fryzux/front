# Итоговый проект PWA: Система управления заметками
## Практические работы 13–18 (Контрольная работа №3)

Данное приложение представляет собой современное Progressive Web App (PWA) для управления заметками с поддержкой реального времени, оффлайн-режима и системы умных напоминаний.

### 🌟 Основной функционал

1.  **Полная оффлайн-поддержка (PR 13, 15)**:
    *   Архитектура **App Shell** обеспечивает мгновенную загрузку каркаса.
    *   Service Worker кэширует статические ресурсы (Cache-First) и динамические страницы контента (Network-First).
    *   Все данные синхронизируются с `localStorage`.

2.  **PWA возможности (PR 14)**:
    *   Манифест приложения с набором иконок разных размеров.
    *   Возможность установки на рабочий стол или мобильное устройство.
    *   Кастомные мета-теги для мобильных платформ.

3.  **Безопасность и App Shell (PR 15)**:
    *   Работа через защищенное соединение **HTTPS** (самоподписанный сертификат mkcert).
    *   Разделение статического каркаса и динамического контента (`/content/`).

4.  **Real-time синхронизация (PR 16)**:
    *   Использование **WebSockets (Socket.IO)** для мгновенного обновления списка задач между разными вкладками/клиентами.
    *   Всплывающие уведомления (Toast) при поступлении новых задач от других пользователей.

5.  **Система Push-уведомлений и напоминаний (PR 16, 17)**:
    *   Интеграция **Web Push Protocol** и VAPID ключей.
    *   Планирование серверных напоминаний с использованием `setTimeout`.
    *   Интерактивные действия в уведомлениях: кнопка **"Отложить на 10 секунд"** (Snooze), отправляющая запрос на сервер для переноса таймера.

### 🚀 Инструкция по запуску

#### 1. Установка зависимостей
```bash
cd pr17
npm install
```

#### 2. Запуск сервера
Сервер настроен на работу по HTTPS (требуются файлы `localhost.pem` и `localhost-key.pem` в папке проекта).
```bash
node server.js
```
Приложение будет доступно по адресу: **`https://localhost:3001`**

> [!NOTE]
> При первом заходе браузер может выдать предупреждение о самоподписанном сертификате. Нажмите "Дополнительно" -> "Перейти на сайт (небезопасно)".

### 🧪 Как проверить работу (Чек-лист)

1.  **Проверка PWA**: Нажмите на иконку установки в адресной строке Chrome. Запустите приложение как отдельную программу.
2.  **Проверка Offline**: В DevTools (вкладка Network) включите режим "Offline". Обновите страницу — приложение должно работать.
3.  **Проверка Sockets**: Откройте `https://localhost:3001` в двух разных вкладках. Добавьте заметку в одной — она появится в другой.
4.  **Проверка Push**: 
    *   Нажмите "Разрешить уведомления" (внизу страницы).
    *   Используйте форму напоминания, выберите время в будущем (через 1 минуту).
    *   Дождитесь системного уведомления.
    *   Нажмите "Отложить" — уведомление придет повторно через 10 секунд.
